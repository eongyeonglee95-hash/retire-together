## 한 줄 요약
보유 화면 필드는 Robinhood 도움말이 가장 구체적으로 적어 두었다(보유 수량·평가금액·평균단가·포트폴리오 비중·오늘 손익·총 손익). 뉴스 쪽은 업계 전체가 "AI가 왜 움직였는지 요약" 방향이다(Robinhood Digests, 토스 AI 시그널·실시간 이슈). 다만 사실과 해석을 화면에서 따로 표시한다고 문서로 밝힌 곳은 없다. 공통점은 "AI 정보는 틀릴 수 있다, 투자 권유가 아니다"라는 고지문뿐이다. 그러니 사실과 해석을 나눠 보여주는 것은 우리가 차별점으로 가져갈 수 있다.

## 1. Robinhood (미국)

**보유 화면 / 종목 상세의 'Position' 영역** — 출처: Robinhood 지원 "Viewing stock details"(날짜 표기 없음, 2026-10 열람)
- Position 영역은 보유했을 때만 나타난다. 필드는 `Shares`(수량), `Market value`(평가금액), `Average cost`(1주 평균 매입가), `Portfolio diversity`(포트폴리오에서 이 종목 비중 %), `Today's return`(오늘 손익), `Total return`(보유 시작 후 손익, 현재가 기준) 6개다.
- 평균단가는 "추정 미실현 손익을 보여주는 참고값이고, 세금 계산에 쓰지 말라"고 적혀 있다. 이전받은 종목처럼 원가가 없으면 `N/A`, 거래를 처리하는 중이면 `-`로 표시한다. — 출처: "Crypto average cost" 지원 문서
- 오늘 손익의 기준: 주식은 그날 거래일 기준, 암호화폐는 자정부터 24시간 기준이다. — 같은 지원 문서
- 홈 화면 보유 목록 한 줄에 무엇이 나오는지, 정렬·묶음 방식은 확인 못 함.

**종목 상세 구조** — 지원 문서에 적힌 순서
차트(1일~5년) → Position → 정기 투자 → About(회사 소개) → Stats(시가총액·PER·거래량·52주 최고/최저) → Volatility(변동성) → News("Show all") → Analyst ratings(매수/보유/매도 비율과 코멘트) → Short interest(공매도 잔고) → Trading Trends(고객·헤지펀드·내부자 매매 흐름) → Financials(재무) → Earnings(예상 EPS와 실제 EPS 차트, 어닝콜 다시 듣기) → Related lists(관련 목록) → People also own(함께 보유한 종목) → History(내 매매 내역)

**뉴스·정보: Cortex Digests**
- AI가 "지금 가격을 움직이는 것으로 보이는 요인"을 쉬운 말로 요약한다. 시장 데이터, 속보, 리서치, 애널리스트 의견을 합쳐서 만든다. Gold 회원 전용이다. 인기 종목·ETF와 거래 가능한 모든 암호화폐가 대상이고, 옵션·선물은 빠진다. 분할·합병 같은 기업 이벤트 중에는 일시적으로 제공하지 않는다. — 출처: 지원 "Cortex Digests"(날짜 표기 없음, © 2026)
- **Portfolio Digests**: 내 포트폴리오 전체가 왜 움직였는지 요약한다. 구성은 시장 배경 / 수익 기여 상위 종목(return drivers) / 상위 등락 종목 / 앞으로 있을 일정(실적·거시지표·촉매)이다. 비교 기준으로 SPY를 항상 함께 그린다. 주식은 직전 거래일 종가 이후를 기준으로 한다. IRA 계좌는 제외된다. — 같은 문서. 2025-12-16 YES/NO 행사에서 발표했다(Robinhood newsroom).
- 고지문: "정보 제공용이며 리서치·추천·투자 조언이 아니다", "정확성을 보장하지 않는다". 사실과 해석을 화면에서 어떻게 구분하는지는 문서에 없다(확인 못 함).
- 영국 출시는 2025-08-19이고 모든 영국 고객에게 무료였다. 미국은 2025년 여름부터 순차 출시했다. — newsroom "Digests by Robinhood Cortex UK"

**최근 기능(2025)** — 투자자용 타임라인 기준
Robinhood Strategies(로보 운용, 2025-03-26) · 세금 손실 수확(Tax-loss harvesting, 2025-11-14) · Robinhood Social(2025-09-10) · Legend의 Cortex 지표·스캐너(2025-09-10). 세부 화면은 확인 못 함.

## 2. 키움증권 (영웅문S#)

**보유 화면**
- 2026-07-30 홈 개편: 잔고 화면으로 이동하지 않아도 홈에서 **계좌별 평가손익과 보유 종목**을 바로 본다. 고객이 가장 많이 요청한 기능이었다고 한다. 홈 메뉴는 주식·커뮤니티·상품·혜택으로 정리했다. 연말까지 '전체 메뉴'와 'My 자산' 화면도 개편할 예정이다. — 아시아경제 CORE(2026-09-21 무렵)
- 홈 한 줄의 구체적인 필드, 색, 정렬 방식은 기사에 없다(확인 못 함).

**간편모드**(2025-09 출시, 기사 2025-10-24)
- 핵심 기능만 모았다. 주문·예수금 충전·환전·소수점 매매를 한 화면에서 처리한다. 조건검색은 단순한 '슬림' 버전이다. 리포트를 웹툰 형식으로 보여주는 '리포툰'과 투자 쇼츠 영상이 있다. 보유·잔고 표시 방식은 확인 못 함.

**뉴스·정보 / 최근 기능**
- 'AI PB': 메뉴와 투자 정보를 대화로 찾아준다. 'AI 커넥트': 환율·유가 같은 거시 변수와 산업·종목의 연결을 설명한다. 연내 ETF부터 시작하고 내년 초 개별주로 넓힌다. — 아시아경제 CORE(2026-09)

## 3. Investing.com

**보유 화면**: App Store 설명에 따르면 주식·ETF·암호화폐 등을 담는 개인 포트폴리오를 만들고 성과와 손익을 추적한다. 한 줄의 필드와 합계 표시 방식은 공식 도움말을 찾지 못해 확인 못 함. 비공식 크롬 확장 프로그램이 Market Value·Daily P/L·Net P/L을 보여준다고 하지만, Investing.com과 무관하다고 스스로 밝혀서 근거로 쓰지 않았다.

**정보 기능** — App Store 설명(열람 2026-10-28, 최신 버전 6.81.0)
- **경제 캘린더**: 중앙은행 결정·GDP·물가·고용 지표·실적 발표를 담는다. 국가·중요도·날짜로 거른다.
- **알림**: 모든 종목에 가격 도달, % 변동, 뉴스, 주요 경제 이벤트 알림을 걸 수 있다.
- **뉴스**: 금융 뉴스와 전문가 분석, 실적 보고를 제공하고 개인화 뉴스 알림이 있다. 뉴스와 분석(의견)을 메뉴로 나누는지는 앱 설명만으로는 확인 못 함.
- **InvestingPro**(유료): 광고 제거, 고급 스크리너, 긴 과거 데이터, 심화 분석. 공정가치·건전성 점수 같은 세부 항목은 이번 출처에서 확인 못 함.
- 종목 상세 구조는 확인 못 함.

## 4. 토스증권

**보유 화면**
- 앱을 켜면 내 계좌 잔액과 투자금 현황을 먼저 보여주고, 시장 지수는 상단에 작게 둔다. 호가창과 복잡한 보조 지표는 뺐다. — 브런치 uibowl "사용성 1위 토스증권 vs 증권앱 1위 미래에셋증권"(날짜 확인 못 함)
- PC(WTS): 내가 투자한 종목, 관심 종목, 최근 본 종목을 **오른쪽 사이드바 패널**에 늘 띄운다. 탐색 탭은 홈·뉴스·주식 골라보기·내 계좌·검색이다. "주식 골라보기"는 기업 가치·수익성·배당 기준 필터다. — 디자인나침반(2024-07-19)
- 한 줄의 필드, 정렬, 묶음 방식은 확인 못 함.

**종목 상세**: 텍스트 출처로는 확인 못 함.

**뉴스·정보** — 토스 공식 소개(열람 2026-10-28)와 다음(daum) 기사(2026-04-29)
- **AI 시그널**: 뉴스와 공시를 분석해 주가가 움직인 핵심 이유를 정리한다. 3개월 평균 종가 기준 Z-score로 **의미 있는 변동이 있을 때만** 분석을 돌린다. 종목에서 섹터·테마·ETF로 넓힐 계획이다.
- **AI 어닝콜**(2025-05): 실시간 번역과 IR 자료를 한 화면에 띄우고, 끝나면 요약한다. 2025-11 개편에서 관전 포인트·챕터별 보기·모아보기를 추가했다(아시아경제). 2026-04에 국내 기업으로 넓혔고, 2026-02 PC 버전을 냈다.
- **실시간 이슈**(2026-03): 국내외 주요 뉴스와 사용자 관심을 합쳐 이슈 20개 순위를 매긴다. 이슈를 누르면 관련 산업·기업 영향을 AI가 분석한다(예: 리튬값 하락과 양극재 기업 원가).
- **증시캘린더**: 주요 경제지표와 기업 실적 발표를 요약한다. 배당 일정이 들어가는지는 확인 못 함.
- **커뮤니티**: 관심사별 방, 팔로우, 인증 배지(실제 주주 표시), 모니터링 체계가 있다.
- 고지문: "AI가 제공하는 정보는 사실과 다를 수 있어요." 환각을 줄이려고 데이터 기반 검증 루프와 사람의 검토를 쓴다고 한다(daum 2026-04-29). 사실과 해석을 화면에서 따로 표시하는지는 확인 못 함.

**최근 기능**: 주식 모으기(금액·기간 설정 자동 매수, 일시정지), 24시간 주문, 모바일·PC 같은 화면.

## 5. 카카오페이증권

**종목 상세**(2024-09-26 개편)
- 정보를 '정보' 탭 아래 섹션으로 모았다. 섹션은 지금 이슈(상·하한가, 신고가·신저가 같은 **가격 사실 알림**), 간편 요약(거래량·시가총액·PER), 개요(기업·ETF 기초 정보), 호가 현황(10호가 누적 잔량 막대), 실적(발표치와 애널리스트 예상치 비교), 배당(최근 5년 배당성향 그래프), 거래원이다.

- 다섯 서비스 모두: 보유 목록 한 줄의 정확한 배치, 정렬과 묶음 옵션, 손익 색(한국 앱의 상승 빨강·하락 파랑, Robinhood의 초록·빨강을 출처 문서로 확인하지 못함)

- 어느 서비스도 사실과 해석을 화면에서 따로 표시한다는 문서를 찾지 못했다.
