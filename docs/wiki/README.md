# llm-wiki — 리서치 위키

규칙·지식 중 "조사해서 알아낸 것"을 둔다. 제품 규칙은 `docs/*_RULES.md`, 숫자의 원천은 `rules/*.yaml`.
쓰고 갱신하는 절차는 `/wiki-research` 스킬 (`.claude/skills/wiki-research/SKILL.md`).

## 목차
### strategies/ — 투자 룰 (저자별)
- (예정) `dalio-all-weather.md` — 레이 달리오 올웨더 원형
- (예정) `kim-sungil-k-all-weather.md` — 김성일 『마법의 연금굴리기』 K-올웨더
- (예정) `parkgomhee.md` — 박곰희 자산배분 기본형

### products/ — ETF·계좌 상품
- (예정) 보유 9종목 자산군 근거, 장기채·원자재 후보(연금저축 적격)

### sources/ — 데이터 출처
- (예정) 공개 시세(네이버·KRX), 증권사 API(미래에셋·한투·키움) 지원 범위
