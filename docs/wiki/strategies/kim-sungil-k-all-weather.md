# 김성일 K-올웨더 포트폴리오 (『ETF 처음공부』 · 『마법의 연금 굴리기』 개정판)
기준일: 2026-10-27 · 상태: 초안

## 요약 (5줄 이내)
- K-올웨더는 김성일이 『ETF 처음공부』(이레미디어, 2022)에서 소개한 포트폴리오로, 달리오 올웨더를 한국 투자자용으로 바꾼 것이다. 『마법의 연금 굴리기』 전면 개정판(에이지21, 2023-10)도 5장 전체를 K-올웨더에 쓴다 ([yes24 ETF 처음공부], [yes24 개정판 ebook 목차]).
- 구성은 미국주식·한국주식·금·한국국채·미국국채·현금성 자산 6개를 "각각 약 1/6씩" ([주간동아 2022-06]). 저자 인터뷰 보도에서는 주식·채권 4개 각 17.5%, 금 15%, 나머지 15% ([매일경제 2023-01]).
- 저자 본인 칼럼(교보생명 뉴스룸, 2026-10-12)은 다른 구성을 보여 준다: 미국·한국·중국·인도 주식 50 / 한국·미국 국채(30년물 ETF) 30 / 금 20 / 현금성 0~40(유형별) ([교보 뉴스룸 4편 2026-10]). 2022·2023 보도 비율과 다르고, 같은 글에 두 버전의 관계 설명은 없다.
- 리밸런싱은 저자 발언 기준 "한 달에 한 번 정도" — 2022-06 인터뷰와 2026-10 칼럼 모두 ([주간동아 2022-06], [교보 뉴스룸 4편 2026-10]). 임계치(밴드) 숫자는 두 자료 모두 없음.
- 저자가 제시한 백테스트(2000-01~2021-08): 연평균 7.3%, MDD 8% ([주간동아 2022-06]). 책 본문의 표는 확인 못 함.
- 우리 키로 접으면 (2022·2023 보도 기준) stock 35 / mid_bond 35 / gold 15 / cash 15, (2026-10 칼럼 MP 기준) stock 50 / long_bond 30 / gold 20 / cash 0 두 후보. 어느 버전을 쓸지, 한국·미국 분리 여부는 사용자 결정.

## 룰 — 저자가 정한 것
### 자산군과 비율
저자 본인 발언이 실린 1차 출처 두 건이 서로 보완한다. 책 본문 표는 열어 보지 못했다.

| 한국주식 | 17.5% | 같음 |
| 한국국채 | 17.5% | 같음 |

| 금 | 15% | 같음 |

- 합계 100. 주간동아는 "6개 ETF에 각각 약 6분의 1씩"이라고 요약하고, 매일경제 보도는 17.5/17.5/17.5/17.5/15/15로 적는다. 저자가 "약"이라 한 만큼 책 표가 최종 기준.
- 분산의 축: 자산·지역·통화 세 가지. 원조 올웨더와의 가장 큰 차이는 환노출이라고 저자가 말함 ([주간동아 2022-06]).
- 블로그 요약 중에는 미국국채 25 / 한국국채 25 / 금 15 (현금 없음) 로 적은 것도 있다. 2026-10-26 재확인에서도 저자 본인 자료(인터뷰 2건, 2026-10 칼럼) 어디에도 이 비율은 없었다. 채택하지 않음(단서로만 둠).
- 버전 정리(2026-10-26 확인): 저자 본인 자료에서 읽힌 K-올웨더는 **(A) 2022·2023 보도 — 6자산 17.5/17.5/17.5/17.5/15/15** 와 **(B) 2026-10 칼럼 — 4개 지역 주식 + 국채 2 + 금 + 현금성, 현금성 비중을 0~40%로 조절** 둘이다. 책(『ETF 처음공부』·개정판) 본문이 어느 쪽인지는 여전히 **책 확인 필요**.

### 리밸런싱 주기·임계치
- 저자 발언: "한 달에 한 번 정도 리밸런싱하면 적당하다" ([주간동아 2022-06]). 주기(시간) 기준이며 편차 임계치(밴드) 숫자는 저자 자료에서 확인되지 않음.
- 2026-10 칼럼도 같은 주기: "한달에 한 번 정도, 비중이 커진 자산을 조금 팔고 줄어든 자산을 그만큼 사서 균형을 맞추면 된다." 예시로 주식이 목표 50%에서 60%가 되면 늘어난 10%p를 팔아 국채·금을 채운다고만 설명, 이탈 몇 %p부터라는 기준은 없음 ([교보 뉴스룸 4편 2026-10]).
- 현금성 자산이 리밸런싱 대상인지는 저자 자료에 명시 없음(칼럼은 "비중이 커진 자산" 기준으로만 설명). 현금성 비중은 위험 수준에 따라 저자가 고르는 값(0~40%)으로 제시됨.
- 블로그들이 적는 "6개월 또는 1년에 한 번"은 블로거 의견. 저자 발언으로 확인 안 됨.
- 백테스트가 어떤 주기로 리밸런싱했는지(월/연)는 미확인 — **책 확인 필요**.

### 적용 계좌·상품
- 저자는 이 포트폴리오를 "연금계좌에서 10년 이상 장기로" 운용하라고 말했고, 본인 개인연금계좌로 10여 년 실천했다고 보도됨 ([매일경제 2023-01]).
- 개정판 구성: 6장 ISA용 포트폴리오, 7장 연금저축펀드용 포트폴리오, 8장 IRP용 포트폴리오 — 계좌별로 따로 장을 둔다 ([yes24 개정판 ebook 목차]). 계좌별 비율 차이는 **책 6~8장 확인 필요**.
- IRP 제약(제도): 위험자산은 적립금의 70%까지. 채권형 펀드, 주식 50% 이하 혼합형, 적격 TDF, 원리금보장상품은 위험자산으로 보지 않음 ([미래에셋 투자와연금센터 2024-01]). K-올웨더는 주식이 35%이므로 이 한도 안에 들어간다(계산: 17.5+17.5=35 < 70). 저자가 IRP 장에서 어떤 종목으로 대응하는지는 **책 8장 확인 필요**.
- 저자가 쓰는 ETF 유형(책 기준 확인 필요): 모든 자산을 국내 상장 ETF로 구성한다는 점은 출판사 소개와 보도에 일관됨 ([yes24 ETF 처음공부], [매일경제 2023-01]). 2022·2023 버전(A)의 구체 종목명은 저자 1차 출처에서 확인 못 함. 2026-10 칼럼(B)에는 저자가 든 예시 ETF가 있다(위 표). 블로그에 돌아다니는 종목 목록(미국채10년선물·국고채10년 등)은 저자 자료와 맞지 않아 적지 않음.
- 주간동아에서 저자가 원조 올웨더 설명에 쓴 미국 상장 ETF(VTI·TLT·IEF·DBC·IAU 등)는 K-올웨더용이 아님 ([주간동아 2022-06]).

### 저자가 말하는 이유
- 시장 타이밍을 맞힐 수 없으므로 자산배분이 필요하다. 직접 인용(한 번): "시장의 상승과 하락을 맞힐 수 없기 때문에 자산배분 포트폴리오 투자가 필요한 거다" ([주간동아 2022-06]).
- 백테스트 2000-01~2021-08: K-올웨더 연평균 7.3%, MDD 8% vs 브리지워터 올웨더(저자 추정 구성) 5.5~5.7%, MDD 14~22% ([주간동아 2022-06]).
- 약세장 구간 2021-12-31~2022-05-31: K-올웨더 −4.9% (MDD 4.9%) vs 올웨더 −11.5~−12.2% ([주간동아 2022-06]). 저자는 "약세장에서 MDD가 한 자릿수"인 점을 의미 있게 본다.
- 목표 수익률은 장기 연 5~10% 수준이라고 설명 ([매일경제 2023-01]). 일반 투자자의 20~30% 기대는 비현실적, 10% 안쪽이 현실적 ([주간동아 2022-06]).
- 변동성(표준편차) 수치는 두 인터뷰 모두 없음. 개정판 5장 "백테스트 성과" 절에 있을 가능성 — **책 확인 필요**.
- 블로그에 떠도는 "2000~2022 연 7.8%, MDD −9.7%"는 블로거가 신동아 그래프를 인용한 것이라 하나 원문을 열지 못함 → 미확인.

## 우리 적용 — strategies.yaml 후보 값 (사용자 확인 전)
자산군 키가 stock / long_bond / mid_bond / gold / commodity / cash 여섯 개뿐이라 저자의 6자산을 접어야 한다. 아래는 **후보**이며 결정은 사용자.

```yaml
k_all_weather:
  name: K-올웨더 (김성일, 『마법의 연금 굴리기』)
  threshold_pp: 5            # 저자 기준 아님. 저자는 "월 1회" 시간 기준(주간동아 2022-06). 우리 기본 ±5%p 유지 여부는 사용자 결정
  min_trade_krw: 100000
  targets:
    stock: 35                # 한국주식 17.5 + 미국주식 17.5 (매일경제 2023-01)
    long_bond: 0             # (A) 2022·2023 보도에는 만기 언급 없음. 2026-10 칼럼(B)은 30년물 장기채 — 아래 (B) 블록
    mid_bond: 35             # 한국국채 17.5 + 미국국채 17.5. (A)의 만기는 미확인. 장기채면 long_bond로 옮김
    gold: 15                 # 매일경제 2023-01
    commodity: 0             # 저자 구성에 원자재 없음
    cash: 15                 # 현금성 자산. 비율 15는 두 기사 조합 추정 — 책 확인 필요
  source: "https://v.daum.net/v/EEjyPz3N25"   # 주간동아 2022-06-25 저자 인터뷰. 비율 숫자는 https://news.nate.com/view/20230123n04482
```


접기 매핑(후보):
- 한국주식 + 미국주식 → `stock`. 지역 비율(50:50)은 `asset_map.yaml`의 종목 단에서 유지하거나, 키를 `kr_stock`/`us_stock`으로 나누는 안(열린 질문 1).
- 한국국채 + 미국국채 → (A)는 만기 미확인이라 `mid_bond` 가정, (B)는 저자가 30년 장기채라고 해 `long_bond`. 현재 `asset_map.yaml`의 mid_bond 기본 종목은 국내 종합채권이라 미국채 10년은 별도 종목 매핑 필요.
- 금 → `gold`, 현금성 자산 → `cash`. 현금 15%를 "리밸런싱 대상 자산군"으로 둘지 "풀 밖 현금"으로 둘지는 열린 질문 3.

## 미확인 · 열린 질문
1. **키 분리**: 한국/미국 주식을 한 `stock`으로 합치면 저자의 통화·지역 분산(50:50)이 사라진다. `kr_stock`/`us_stock`, `kr_bond`/`us_bond` 키를 추가할지 — 사용자 결정. 추가하면 올웨더·박곰희 템플릿과 shock 표도 같이 늘어난다.
2. **국채 듀레이션**: 2026-10 칼럼(B)은 30년 장기채로 확인. 2022·2023 버전(A)·책의 만기는 여전히 미확인 — 『ETF 처음공부』 1장, 개정판 5장 "국채" 절 확인. 블로그의 "10년물"은 저자 자료로 확인되지 않음.
3. **현금성 자산**: (B)는 초단기채권·CD/머니마켓 ETF를 예시로 들고 비중을 0~40%로 조절한다. (A)의 15%가 무엇이었는지·책 기준 비율은 책 확인. 현금성을 리밸런싱 대상으로 둘지는 저자가 명시하지 않았음 — 사용자 결정.
4. **리밸런싱 주기**: 저자 "월 1회"(2022·2026 두 자료)로 확인, 밴드 숫자는 저자 자료에 없음. 저자 "월 1회" vs 우리 "±5%p 밴드" 중 무엇을 쓸지 — 사용자 결정. 백테스트의 리밸런싱 주기는 책 확인.
4-1. **버전 선택**: (A) 2022·2023 보도 비율과 (B) 2026-10 칼럼 구성이 다르다(지역 4개 주식, 30년 국채, 현금 0). 책 최신판이 어느 쪽인지, 어느 버전을 우리 `k_all_weather`로 쓸지 — 책 확인 후 사용자 결정. (블로그의 25/25 버전은 저자 자료에서 어디에도 없음.)
5. **계좌별 포트폴리오**: 개정판 6~8장(ISA·연금저축·IRP용)이 5장 K-올웨더와 같은 비율인지, IRP에서 어떤 종목으로 바꾸는지 — 책 확인.
6. **초판(2019) 포트폴리오**: 개정판에서 "크게 바뀌었다"는 추천사만 있고 내용 미확인. 사용자가 가진 책이 초판이면 비율이 다를 수 있음.
7. **저자 영상**: 자이앤트썰(2022-11 촬영, 김성일 리치고 CIO)·ETF아는형(업라이즈 김성일 대표 출연) 유튜브는 2026-10-26 재시도에도 페이지에 설명란·댓글·자막이 노출되지 않아 제목만 확인됨. 비율·주기 발언 확인 불가.
8. **원문 접근**: 2026-10-27 재시도, 매일경제 원문·AMP 주소는 도구가 접속 차단(미열람). 네이트 전재본을 다시 읽어 숫자 재확인함: 한국주식 17.5·미국주식 17.5·한국채권 17.5·미국채권 17.5·금 15·나머지 1개 15(이름은 인코딩 깨짐), 합 100. 백테스트 기간 2000-01~2021-08, 연금계좌 10년 장기투자 권고. 기사에 리밸런싱 주기 문장 없음. 기존 표의 숫자와 같아 값 변경 없음.
9. 2026-10-27 재시도 요약: 저자 유튜브 2건 설명란·자막 여전히 미노출(미확인), 저자 칼럼·인터뷰 추가 검색에서 K-올웨더 비율·국채 만기 언급 없음(업라이즈 대표 선임 기사에서 경력·저서만 확인), 『ETF 처음공부』·개정판 yes24·교보 미리보기는 지난번 이후 새로 확인된 표 없음. 질문 2·3·4-1·5·6은 그대로 책 확인 필요.
