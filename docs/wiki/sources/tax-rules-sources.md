# TAX_RULES 출처·기준일 점검
기준일: 2026-10-26 · 상태: 초안

## 요약 (5줄 이내)
- `docs/TAX_RULES.md` §1~§6의 숫자 28개를 국가법령정보센터 조문(소득세법 [시행 2026-01-01, 법률 제21221호], 시행령 [시행 2026-10-01, 대통령령 제36737호], 조특법 [시행 2026-09-18]), 국세청 안내, 기획재정부·재정경제부 보도자료, 국민연금공단 안내와 대조했다.
- 일치 26개, 불일치 1개(종신형 연금 세율 4.4% → 현행 3.3%), 보완 필요 1개(퇴직소득 20년 초과 50% 구간은 2026-01-01 이후 수령분부터 적용 — 적용 시기 명시 없음).
- ISA 비과세 한도 500/1,000만원·납입한도 4,000만원으로 바뀌었다는 블로그 정보는 현행 조특법 §91의18 원문과 다르다. 현행은 200/400만원, 연 2,000만원·총 1억원 그대로다.
- 2027년 시행 예정(정부안, 국회 심사 중): 생산적금융 ISA 신설, 연금계좌 추가납입·세액공제 추가한도에 생산적금융 ISA 전환금 포함, 청년(15~34세) IRP 세액공제율 가산. 일반 ISA 5년 제한·이월 폐지는 2026-09-01 정부안에서 철회됐다.
- 사적연금 1,500만원 기준선·세액공제 600/900만원·납입한도 1,800만원을 바꾸는 정부안은 확인 범위 안에서 없다.

## 항목별 확인 (표)
세율은 지방소득세(소득세의 10%) 포함 표기. 조문은 본세 기준. 확인일은 모두 2026-10-26.

## 수정 제안 (TAX_RULES / REBALANCING_RULES §3에 반영할 후보, 사용자 확인 전)
1. **§1 종신형 세율 4.4% → 3.3%** (소득세법 §129①5의2다, 2025-12-23 개정, 2026-01-01 이후 수령분). 종신형은 연령 세율과 비교해 낮은 쪽 적용이라는 문구도 추가 후보.
2. **§2 20년 초과 50% 구간에 적용 시기 주석**: "2026-01-01 이후 연금수령분부터(법률 제21221호)". 2025년 이전 수령분 시뮬레이션에는 60% 적용.
3. **§1 1,500만원 계산 제외 항목에 "의료목적·부득이한 사유 인출(시행령 §20의2)" 추가** — 연금소득으로 과세되지만 1,500만원 합계에서 제외(§14③9나).
4. **§2 연금수령연차 설명 문구**: "개시 신청 시점"이 아니라 "최초로 연금수령할 수 있는 날이 속하는 과세기간"이 기산점(시행령 §40의2④). 55세·5년 요건을 채운 해부터 센다는 뜻이므로 CALCULATION_RULES 구현 시 구분.
5. **출처 절 교체**: 현재 "국세청 안내, 금융사 약관, 해설" 식 서술을 이 페이지의 조문 링크(법률·대통령령 번호, 시행일)로 바꾸는 것을 제안.
6. **§5 ISA 참고 문구**: "비과세 한도·납입한도 상향(500/1,000만원, 4,000만원)은 2026-10-26 현재 법에 없음" 주석. 블로그에 퍼진 잘못된 정보가 많아 Agent 컨텍스트에 명시해 두는 편이 안전.
7. (REBALANCING_RULES §3 관련은 `pension-account-rules.md` 참조.)

## 미확인 · 열린 질문
- 2025-12-23 조특법 §91의18③ 개정(법률 제21221호와 같은 날)으로 ISA 운용 재산 범위에 무엇이 바뀌었는지 조문 신구 비교를 열지 않았다. 비과세 한도·납입한도 조항(①②③5)은 바뀌지 않은 것을 현행 조문으로 확인.
- 2026 세제개편안 상세본(8/3) 원문 PDF는 열지 않았다(국회도서관 목차 페이지와 9/1 수정사항 첨부만 확인). 연금계좌 관련 수치는 2차 해설 기준이라 상세본으로 재확인 필요.
- 소득세법 §129①5의3 적용례(부칙)의 정확한 문구는 법률 부칙을 열지 않았고 국세청 안내("2026.1.1. 이후 수령분")에 의존.
- 국민연금 개시연령의 법적 근거 부칙(법률 제8541호 부칙 등)은 조문을 직접 열지 않았고 공단 안내 페이지로 확인.
- 연금소득공제(소득세법 §47의2, 900만원 한도) 등 종합과세 시 공제는 TAX_RULES 범위 밖이라 점검하지 않음. CALCULATION_RULES에서 종합과세 시뮬레이션을 만들면 추가 점검 필요.
- 건강보험료 산정에 어떤 연금소득이 들어가는지는 국민건강보험법령 확인이 필요(이번 범위 밖).
